Striplight PRO manual

Striplight PRO reviews scanned microfilm rolls: it shows the strips, finds the page frames on them, lets you fix and mark them, and exports every frame as a clean JPEG into the folder structure your archive needs.

Getting started

Open a roll with Open (Ctrl+O) or drop into the demo roll from the start screen to try everything without real scans.

  • .idf — the QuantumScan roll file written by the scanner. Opening it reads the roll and its detected frames.
  • .qpf — a QuantumScan project (frames and markers).
  • .slf — a Striplight project. It holds everything QuantumScan has plus Striplight's own data: notes, suggested markers, per-frame tone, export settings.

If you open an .idf and a saved Striplight project for that roll exists next to it, Striplight opens the project instead, so your work is never lost. Recent rolls are listed on the start screen.

Save (Ctrl+S) writes the .slf. Save as (Ctrl+Shift+S) can also write a .qpf for QuantumScan (Striplight-only data is left out of that file). An orange Unsaved chip in the app bar shows unsaved changes; closing asks before anything is lost.

The .slf keeps the complete state of the project: frames and markers, tone and orientation, the export folder and all naming and output options (archive list included), the CW setting, the size check and every panel field (detection, ignore area, range, suggestions, repair, trim). Reopening it brings back exactly what you saved — nothing is reset to defaults. Older .slf files without this information open with the current defaults.

Striplight never changes the scanned strip files. Everything you do is stored in the project file.

Typical workflow

  1. Open the roll (.idf, or your saved .slf).
  2. Tune the tone in Adjust until frames look white on a black film background (gamma, brightness, contrast).
  3. Detect frames in Detect — the whole roll or a strip range. Watch them appear live.
  4. Fix the frames: move, resize, draw, merge, split, fill gaps, join close fragments, expand, trim (Frames, Repair tools).
  5. Mark folder starts: let Striplight suggest markers, check them, make them markers.
  6. Check the markers in the preview window: jump from marker to marker (F / G) and compare each page with the target banner.
  7. Export (Export) into marker folders or archive-list folders.
  8. Save the project.

The screen

  • App bar (top): roll name and size, unsaved chip, Open / Save as / Save, theme, keyboard shortcuts, Help, language.
  • Tool rail (left): Frames, Detect, Adjust, Export, Notes. Each opens its panel on the right.
  • Strip view (middle): the strips of the current page, turned upright, with every frame drawn on them.
  • View toolbar (over the strips): pages, zoom, strips per row, Auto, # strip numbers, Multi edit, CW orientation.
  • Legend and roll overview (bottom): the colour key, and a bar for the whole roll showing markers, odd sizes, selection and exported frames. Click or drag it to jump.
  • Status bar: messages on the left, the position under the mouse (strip, line, x, frame size) on the right.

Moving around

  • Pages: X / C, Page Up / Page Down, Home / End, the mouse wheel, or type a page number.
  • Zoom: Ctrl+wheel, + / −, or the slider.
  • Strips per row: set the number, or switch on Auto to fit as many as the window allows.
  • # shows strip numbers. CW switches the source orientation (clockwise + mirror instead of counter-clockwise) for scanners that store strips the other way round.
  • Jump: F / G next / previous folder marker; Next odd size, Next small and Next big find the next red frame (see Size check).

Strip images come from the roll's preview files, so pages appear quickly even on network shares. Previews are re-rendered when you change the tone.

Working with frames

Selecting

  • Click a frame to select it, Ctrl+click to add or remove, Shift+click for a range.
  • Ctrl+A selects all, Ctrl+D or Esc selects none, Select page selects the visible page.
  • A single selected frame shows its details (position, size, strips, own settings) at the bottom of the Frames panel.

Moving, resizing and drawing

  • Move: drag a selected frame. Past the end of a row it continues in the next row, like the film itself.
  • Resize: drag an edge or a corner handle. Resizing also continues into the next or previous row.
  • Draw: drag on empty film to draw a new frame.
  • Esc during a drag puts the frame back.

Multi-edit

Switch on Multi in the view toolbar, select several frames and drag an edge or corner of one of them: the same edge of every selected frame moves by the same amount. Each frame stays inside the roll and keeps a minimum size.

Right-click menu

Right-click a frame or the film for: preview, folder marker, select / delete the folder section (from a marker to the next one), clear exported marks, set the detection start or end at that strip, clear per-frame settings and delete.

Size check (odd-size frames)

Frames much longer or shorter than the usual frame are flagged red — often two pages detected as one, or a fragment. The check compares each frame's length along the film with the median frame length of the roll.

  • Flag oversized frames + % longer than the median (0–200, default 50): a frame more than that much longer than the median is flagged.
  • Flag undersized frames + % shorter than the median (0–99, default 50): a frame more than that much shorter is flagged.
  • Switching a check off flags nothing of that kind. The colours update live while you move the sliders; the line below shows the median and how many frames are flagged.
  • Select flagged selects them all; Next odd size, Next small and Next big jump from the selected frame to the next one.

The settings are remembered.

Repair tools

  • Fill gaps: neighbouring selected frames are stretched to meet in the middle of the gap between them.
  • Join close: selected fragments closer than the join gap are joined into one frame. Show reach draws an orange band after each selected frame showing how far the join reaches.
  • Expand selected: grows the selected frames by the given pixels on each side as seen on screen (left, right, top, bottom). Negative values shrink.
  • Trim: switch on Show trim lines, set or drag the yellow lines at the top and bottom of the strips, then Apply trim to all frames: every frame reaching into the yellow bands is clipped to them.
  • Per-frame orientation: give the selected frames their own rotation, mirror or negative (they get the orange "own settings" colour). Clear returns them to the global orientation.

Detecting frames

Detection finds bright frames on dark film using the preview strips. Frames that start inside the detected range are replaced; frames outside it stay.

Before you detect

With Use the Adjust tone on, detection sees exactly what the strips show. Go to Adjust and push gamma, brightness and contrast until the pages are close to white on a black background — then detect. This works much better than detecting the raw scan.

Sensitivity

  • Threshold (1–254): how bright a pixel must be (after the tone curve) to count as page.
  • Min width / Min length: smaller bright areas are ignored (full-resolution pixels).
  • Show frames live: frames appear while detection runs and the view follows the strip being read.
  • Auto threshold per strip: picks the threshold for each strip from its brightness histogram (the split between page and background). Useful when the lighting changes along the roll; strips of empty film fall back to the manual threshold.
  • Dark frames on light film: inverts detection.

Advanced controls

SettingWhat it does
Min runA bright pixel only counts inside a run of at least this many bright pixels across the film. Removes dust and grey background that make boxes too wide. Try 16–30 px.
Touch widthDark gaps up to this size across the film still join two bright parts of a line.
Touch lengthDark lines up to this length along the film do not cut a frame in two (also across strips).
Max lengthLonger frames are split into equal parts (0 = off).
Overscan width / lengthGrows every detected frame by a margin (negative values shrink).

Defaults resets them. Detection settings are remembered on this computer.

Range and ignore area

  • Whole roll or Strip range. Typing a From / To strip, or right-clicking a strip and choosing Set detection start / end here, switches to the range; green and red markers show it on the strips. The Detect button says what it will do.
  • Pause / Resume holds the detection and goes on. Stop ends it after the current strip and keeps the frames found so far; Continue then carries on from the next strip to the end of the original range — the frame that was cut by the stop grows on into the next strip, so it stays one frame. Cancel throws the whole run away.
  • Ignore top / bottom with Use and show the ignore area: blue bands at the strip edges are left out of detection. Drag the blue lines or type the values.

Folder markers and suggestions

A yellow folder marker starts a new export folder. Striplight can suggest folder starts from unusually large gaps between frames (the empty film between documents).

  • Suggest markers marks the likely starts in purple. Strictness (10–200): higher means fewer, surer suggestions; moving the slider updates the suggestions. On real rolls 80–120 works well.
  • Suggest the frame before the gap marks the last frame before a gap instead of the first after it.
  • Toward start / Toward end suggest only before or after the one selected frame.
  • Select suggested, then check them; Z toggles a single suggestion. Make markers turns all suggestions into folder markers.
  • Clear suggested, Clear selected, Every Nth (clear every Nth suggestion before / after the selected frame), and Clear markers before / after the selected frame tidy up.
To check markers, open the preview window on a marker and press F / G to jump between markers. The big target banner shows the folder number and the target folder and file name, so you can compare them with what is written on the page.

Adjust: tone and orientation

Tone

  • Method: Striplight current (default), Quantum-like (QuantumScan slider ranges: contrast 64 and gamma 0 are neutral), curve methods, and adaptive methods (Auto levels, Local contrast (CLAHE), Exposure balance, Background flatten) with a Strength slider.
  • Contrast, Brightness, Gamma change the strips live and apply to the preview and the export.
  • Rescue curves: shadow lift, highlight recovery, S-curve, document rescue, soft contrast — for faded or dense film.
  • Show on strips off shows the untouched scan in the strip view.

Adaptive methods analyse each frame on export; the strips show a per-strip approximation, so use the preview (Enter) for the exact result.

Own tone for selected frames

Under Apply tone to, choose Selected frames: the sliders now show the selected frame's tone, and every change gives the selected frames their own complete tone (method, curves, sliders, strength). That tone is locked: changing the global tone later never touches those frames. They are shown in their own tone on the strips, in the preview and in the export.

  • Select own-tone selects every frame with its own tone.
  • Use global tone puts the selected frames back on the global tone.

Sharpen and orientation

Sharpen (mode and amount) applies to the preview and export of all frames. Orientation (rotation, mirror, negative) applies to all frames except those with their own orientation.

Preview window

Press Enter or double-click a frame to open the preview: the frame exactly as it will be exported. It is a separate window — keep it on a second screen, or pin it On top (T). Clicking a frame in the main window shows it here.

  • X / C (or arrows) previous / next frame; Step sets how many frames they move. G / F jump between folder markers.
  • Wheel zooms around the cursor, drag pans, double-click toggles fit / 1:1, 0 fit, 1 1:1, Q full quality.
  • R / Shift+R rotate, M mirror, N negative — for this frame only. A toggles its folder marker.
  • The target banner shows the folder number, the target folder and the file name of this frame. I hides or shows it. Esc closes the window.

Export

Export writes every frame (or only the selected frames) as a JPEG, exactly as the preview shows it. Under the naming settings, a path preview shows where the selected frame will go — check it before a long export.

Output folder: a project without a saved output folder starts with the QuantumScan default, a frames folder next to the project file, filled in as normal text — edit it (e.g. add a subfolder) and it is saved with the project.

Quantum folders (one folder per marker)

Each folder marker starts a new numbered folder in the output folder (with Counter digits 5: 00001, 00002…); frames before the first marker go to folder 1. Files are named File prefix + counter, e.g. page_00001.jpg, and the counter starts again at 1 in every folder.

With Folder per marker off all files go into the output folder itself. Because the counter restarts at each marker (as in the Lazarus edition), use this only for rolls without markers.

Archive list (one row per marker)

Paste one row per folder marker. The parts of a row, separated by ;, become nested folders and the start of the file name:

;73;524;0;0;80
;73;524;0;0;81

Leading ; are ignored. The first marker's frames go to 73\524\0\0\80\73_524_0_0_80_00001.jpg, …_00002.jpg and so on; the second marker's to 73\524\0\0\81\. The path preview shows how many folders and list rows there are — if rows are missing it turns red before you export.

Build from folders… creates the list from an existing folder structure: choose the root folder and Striplight adds one row for every folder that has no subfolders, in natural order (2 before 10), e.g. root\73\524\0\0\80 becomes ;73;524;0;0;80. Folder names containing ; are skipped.

Output options

  • Quality (JPEG 1–100), Workers (frames built in parallel), Strip cache (full strips kept in memory).
  • Skip existing files — continue an interrupted export.
  • Use previews when strips are missing — lower resolution, but no gaps.
  • Stage through local temp — write each file locally first, then copy it to the network share (faster and safer on slow shares).
  • Prepare folders creates all output folders now, without exporting.
  • Follow the export turns the strip view to the page being exported, so you can watch it progress (pages only move forward).

During export: Pause / Resume and Stop. Exported frames turn blue. When the export is done, Open report appears for the handover report (archive-list naming). Failed frames are listed under the progress bar; click one to show it. Re-export failed then exports only those frames again — for example after a network share came back.

Handover report

After exporting a roll with the archive list naming, Report (Export panel) builds the series report for your Excel sheet — one row per series folder this roll wrote:

ColumnContent
IdentifierThe series: archive\fonds\continuation\series, e.g. 1\63\0\1.
SignaturesThe signature folders of this roll in that series, in natural order; consecutive numbers become ranges (1-9, 26-27), names with letters stay as written.
Microfilm numberThe roll's microfilm numbers, taken from the project folder name: 123-321_400_405-500 becomes 123-321; 400; 405-500. Edit the field if needed — your text is saved in the project; the ↺ button goes back to the folder name.
Units / Files / GBNumber of signatures, number of exported files and their size (exact bytes ÷ 1,000,000,000, rounded once to two places).
DirectoryThe series folder on disk.

Only this roll's own files are counted, and every file is checked on disk when the report opens (Refresh counts again). Rows with files missing on disk are marked red, and frames without an archive-list row are reported under the table. The same identifier can appear in reports of several rolls — that is expected.

Copy to Excel copies the rows without headers (switch on Copy with headers if you want them), ready to paste into a shared sheet. Text columns are pasted as text, so 007, 5-6 or 1; 2 are not turned into numbers or dates.

Notes

The Notes panel is a Markdown editor for the roll: damage, missing frames, box labels, questions for the archive. Notes are saved in the .slf project.

Language and translations

The EN / PL button in the app bar switches between English and Polish. Both windows reload in the new language; the open roll stays open.

To change a translation, choose Edit translations in that menu. Striplight copies pl.json to %APPDATA%\StriplightPRO\lang\ and opens the folder. Each line maps the English text to the translation; edit the right-hand side and switch the language again to see it. Your file overrides the built-in one and survives updates. Lines you delete fall back to the built-in translation.

Preview cache

The preview cache button in the app bar copies the roll's small preview images from the network share to this computer, so pages load quickly even when the share is slow or the PC is busy exporting. Only previews are copied — full strips stay where they are.

  • Cache previews locally: previews are copied the first time they are needed (strip view, detection) and read from the local copy afterwards. The setting belongs to this computer.
  • Cache folder: by default %LOCALAPPDATA%\StriplightPRO\PreviewCache; choose another (fast, local) folder if you like. Each roll gets its own subfolder.
  • Cache whole roll now copies every preview of the open roll in the background (low priority), with progress and Stop. Clear this roll / Clear all caches free the space again.
  • Cache manager: add several projects (Add projects… for .idf / .slf files, Add folder… for every roll under a folder) and press Start — they are cached one after another while you work, e.g. tomorrow's rolls overnight.

While exporting, the export runs at below-normal priority, so the strip view and the preview stay responsive.

Files, settings and tips

  • Settings (window, theme, language, shortcuts, last folders): %APPDATA%\StriplightPRO\settings.json.
  • The strip view and detection use the roll's preview files; export uses the full strips. If previews are missing, the status line after detection says how many and where they were expected.
  • On network shares, keep Workers moderate (4–8) and switch on Stage through local temp.
  • Striplight needs the Microsoft Edge WebView2 Runtime (already part of Windows 10/11).
